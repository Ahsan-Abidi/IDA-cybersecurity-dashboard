# 🚨 AI-Powered IoT Cybersecurity Dashboard

A Flask-based web application that analyzes IoT device logs to detect cyber threats using rule-based logic and machine learning.

## 🔥 Features

* 🔐 User Authentication (Login System)
* 📊 AI-Based Anomaly Detection (Isolation Forest)
* 🚨 Real-Time Attack Detection & Alerts
* 📈 Interactive Dashboard with Charts
* 📡 Live Log Monitoring
* 💾 MySQL Database Integration
* 📥 Downloadable Security Reports
* 🔍 Log Search & Filtering

## 🧠 Technologies Used

* Python (Flask)
* Machine Learning (Scikit-learn)
* MySQL
* HTML, CSS, JavaScript
* Matplotlib
